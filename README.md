## New Features in This Fork

### Subfolder Tabs & Drag-and-Drop

- Subfolders are shown as horizontal tabs for quick in-page navigation
- Drag-and-drop reordering of subfolder tabs
- Right-click a subfolder tab for a context menu (new, edit, delete, etc.)

### Appearance Settings

- **Tab font size**: independently configurable for top-level folders and subfolders
- **Dial BG Color**: customize tile background color with alpha support and live preview
- Settings panel redesigned into a two-column layout with clearer grouping

### Refresh Enhancements

- **Refresh Title**: update a single dial's bookmark name without re-fetching its thumbnail
- **Refresh All Titles**: bulk-update all bookmark names in the current folder

### Import/Export Improvements

- More reliable import/export with several edge-case fixes

## Fork 新增功能

### 子文件夹标签页与拖拽

- 子文件夹以横向标签页形式展示，可在同一页面内快速切换
- 支持在子文件夹标签之间拖拽排序
- 右键子文件夹标签可呼出菜单（新建、编辑、删除等）

### 外观设置

- **标签页字体大小**：可分别设置顶级文件夹和子文件夹标签的字体大小
- **拨号背景色（Dial BG Color）**：自定义拨号卡片背景色，支持透明度，实时预览
- 设置面板重新设计为双栏布局，分组更清晰

### 刷新功能增强

- **刷新标题（Refresh Title）**：单独刷新指定拨号的书签标题，不重新抓取缩略图
- **批量刷新所有标题（Refresh All Titles）**：一次性更新当前文件夹下所有拨号的书签名称

### 导入/导出改进

- 导入导出流程更稳定，修复了若干边界情况下的错误

## About

A better new tab page and bookmark manager (speed dial) that respects your privacy, inspired by Opera

- Automatically fetches site thumbnails using open graph standard
- Supports custom images, sorting, searching, and folders
- Uses the native bookmarks library so speed dials can be synced by the browser
- Supports limited importing from other browser extensions
- Available for Brave, Chrome, Edge, Firefox (~~including Android~~), Opera and Vivaldi
- Lightning fast UI: no ads, trackers, or bs
